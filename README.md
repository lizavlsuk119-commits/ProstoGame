# Prosto Games — демо-магазин игр

Учебный проект: тёмный игровой магазин на чистом HTML, CSS и JavaScript.

## Что внутри

- `index.html` — главная страница: каталог из 16 игр, фильтры, поиск, сортировка, корзина, список желаний, модальные окна.
- `info.html` — страница помощи: активация ключей, гарантия и возвращение, поддержка.
- `style.css` — все стили, включая адаптив и слайдер.
- `script.js` — логика магазина, слайдер, корзина, localStorage.
- `assets/logo.png` — логотип для тёмной темы (белый, прозрачный фон).

## Как открыть

Просто открой `index.html` в браузере. Для проверки через локальный сервер:

```bash
python -m http.server 8080
```

Потом зайти на `http://127.0.0.1:8080/`.

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub (например, `prosto-games`). Галочку README можно не ставить.
2. Загрузи в корень репозитория файлы:
   - `index.html`
   - `info.html`
   - `style.css`
   - `script.js`
   - папку `assets` (внутри `logo.png`)
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/(root)**
5. Нажми **Save** и подожди 1–2 минуты.
6. Сайт будет доступен по адресу:
   `https://ТВОЙ-ЛОГИН.github.io/prosto-games/`

Важно: `index.html` должен лежать именно в корне репозитория, иначе главная страница не откроется.

## Что работает

- 16 игр, фильтры по жанру и платформе, поиск, сортировка.
- Переключение вида каталога: сетка / слайдер (стрелки, точки, клавиатура).
- Корзина: количество, удаление, итоговая сумма, демо-оформление заказа.
- Список желаний с сохранением в `localStorage`.
- Отдельная страница помощи в стиле главной.
- Адаптив: 390 / 768 / 1281 px, без горизонтального скролла.

## Примечание

Это демо: реальная оплата не списывается, ключи не отправляются. Обложки игр загружаются с Wikipedia, поэтому нужен интернет. Данные корзины и желаний хранятся только в браузере.
